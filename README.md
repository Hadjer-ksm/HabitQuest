## 🌟 English Description

**HabitQuest** is a free, privacy-first, open-source gamified habit tracker built for individuals who want to master their daily routines through the excitement of RPG games. Every habit completed gives you XP and Gold, helping you level up and purchase your own custom rewards!

### ✨ Core Features
* **🎮 RPG Gamification:** Leveling system, XP accumulation, and Gold rewards for staying disciplined.
* **🔥 Streak Tracking:** Keep your daily momentum going with visual streak counters.
* **🛒 Custom Reward Shop:** Spend your hard-earned Gold on custom real-life rewards (e.g., "Watch 1 episode of a show").
* **🔒 Privacy First:** All data is saved securely on your device using `IndexedDB`. No cloud trackers, no data leaks.
* **📱 Progressive Web App (PWA):** Install it on your phone or desktop like a native app. Works offline!
* **🌐 Dual Language Support:** Full native support for both **English** and **Arabic** with proper RTL layouts.
* **🌙 Clean Modern UI:** Seamlessly switch between beautiful Light and Dark themes with modern SVG iconography.

## 🌟 الوصف باللغة العربية

**HabitQuest** هو تطبيق مجاني، مفتوح المصدر، ومصمم بأسلوب الألعاب (Gamification) لمساعدتك على الالتزام بعاداتك اليومية وتحقيق أهدافك من خلال تحويل حياتك إلى لعبة أدوار (RPG) ممتعة. كل عادة تنجزها تمنحك نقاط خبرة (XP) وذهب (Gold) لترفع مستواك وتشتري مكافآتك الخاصة!

### ✨ أبرز المميزات
* **🎮 نظام الألعاب الـ RPG:** مستويات، نقاط خبرة (XP)، وجمع الذهب لتشجيعك على الاستمرار.
* **🔥 عداد الالتزام (Streak):** تتبع عدد الأيام المتتالية التي حافظت فيها على عادتك.
* **🛒 متجر المكافآت المخصص:** استبدل الذهب الذي جمعته بمكافآت حقيقية تحددها بنفسك (مثل: "مشاهدة حلقة من مسلسلي المفضل").
* **🔒 خصوصية تامة:** تُحفظ جميع بياناتك محلياً على جهازك باستخدام تقنية `IndexedDB` دون أي خوادم خارجية.
* **📱 تطبيق ويب تقدمي (PWA):** يمكنك تثبيته على هاتفك أو حاسوبك والوصول إليه بدون إنترنت.
* **🌐 دعم كامل للغتين:** واجهة احترافية تدعم اللغتين **العربية** والإنجليزية بشكل كامل (RTL/LTR).
* **🌙 واجهة عصرية وبسيطة:** تبديل سلس بين الوضعين الليلي والنهاري بأيقونات SVG جذابة.

## 🚀 How to Run Locally / التشغيل المحلي

To run this project locally on your machine:

1. **Clone the repository** (استنساخ المشروع):
   ```bash
   git clone https://github.com/hadjer-ai-web/HabitQuest.git
Navigate to the project folder (الدخول إلى مجلد المشروع):

bash
cd HabitQuest
Run a local server (تشغيل خادم محلي):
You can use any static server. For example, using VS Code with the "Live Server" extension, or using Python:

bash
# Python 3
python -m http.server 8000
Or using Node.js (if you have http-server installed):

bash
npx http-server -p 8000
Open your browser (افتح المتصفح):
Navigate to http://localhost:8000 and start using HabitQuest!
